# My Game Store — Version 1

A simple mobile-friendly storefront with:

- 30-day plan
- 90-day plan
- Demo checkout
- Demo account/entitlement display
- Demo download button

## Important

This version does **not** process real payments.

The checkout is intentionally a demo. Do not treat the browser's JavaScript as proof of payment.

For the production version, add:

1. User authentication
2. A backend/server
3. A database
4. A supported payment provider
5. Payment-provider webhook/server verification
6. Server-side entitlement and expiry handling
7. Protected APK download
8. Purchase history

## Deploying to Cloudflare Pages

You can upload this project to a GitHub repository and connect that repository to Cloudflare Pages.

The website entry point is:

`index.html`
